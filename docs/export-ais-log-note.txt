- Endpoint: GET /admin/export-ais-log
- Query Params: รองรับ `startDate` แบบ required และ `endDate` แบบ optional โดยทั้งสองค่าต้องอยู่ในรูปแบบ YYYY-MM-DD
- Response Format: เมื่อสำเร็จจะส่งกลับไฟล์ Excel ประเภท application/vnd.openxmlformats-officedocument.spreadsheetml.sheet
- Validation: ตรวจสอบรูปแบบวันที่ และตรวจสอบว่า `startDate` ต้องไม่มากกว่า `endDate`
- Documentation Update: เพิ่ม Swagger decorators ใน `admin.controller.ts` และสร้างไฟล์ OpenAPI ที่ `docs/apidog/admin-export-ais-log-api.json` สำหรับ import เข้า ApiDog
